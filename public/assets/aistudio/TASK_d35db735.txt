步骤 1 ｜ 做出首页和单词卡
首页：今天是第几天、今天还有几个词没背、今日进度圆环、开始今天的学习按钮。

单词卡：单词、音标、词性、中文释义、英文例句和翻译，点小喇叭能发音。

提示词：

提示词 · 点右侧按钮整段复制
复制提示词
帮我做一个背单词网页，做成一个单独的 HTML 文件，双击用浏览器打开就能用，不联网也能用。

【目标】
两屏：一个首页（打开就知道今天要干嘛），点进去是学习页（一屏一个单词卡）。
这一轮先要这两屏能跑起来：能看首页、能翻词、能发音。按天推词、小测这些后面再让你加。
给完全不会写代码的成年人用，他要的是「点开就能背」，不是一个功能很多的学习系统。

【首页长什么样】
- 顶部一行：左边显示当前词库名和「第 1 天」，右边显示「连续打卡 0 天」
- 中间一块：写「今天还有 7 个词没背」，下面一行小字「新词 7 · 复习 0」（复习是后面才加的，现在就是 0）
- 一个圆环进度：中间显示「0/7」，下面写「今日进度」
- 一个大按钮：「开始今天的学习」（点它才进学习页，打开不要自动进单词卡）
- 按钮下面一行小字提示：「背完 → 小测试 → 导出战绩卡」（七个字写全，不要写成「导出战卡」）

【学习页（单词卡）长什么样】
- 顶部显示「第 1 / 7 个」和一个进度条，左上角一个返回按钮能回首页
- 中间一张大卡片，从上到下依次是——英文单词（字号最大）、音标、词性和中文释义、一条英文例句加中文翻译。单词右边放一个小喇叭按钮
- 底部两个大按钮：左边「不认识」，右边「认识」，点了就换到下一个词
- 键盘也能操作：← 不认识，→ 认识，空格朗读

【词表：这一轮直接放 50 个】
放 50 个大学英语四级高频词，用 WORDS 数组存（每个词一个对象，不要塞在 HTML 里）。每个词 8 项：
单词 / 音标 / 词性 / 中文释义 / 英文例句 / 例句翻译 / 构词 / 同族词
其中前 6 项放 WORDS，后 2 项单独放一个 DETAIL 映射（按单词存，第 3 步点「不认识」时展开用），两份一一对应。
例：ability 的构词写「able（能够的）+ -ity（名词后缀）」，同族词写「able adj. 能够的 · enable v. 使能够 · unable adj. 不能的」。
要求：例句短（≤15 个词）、好懂；词性用缩写 n. / v. / adj. / adv.；单词、释义、例句都不重复；不编造单词；字段不为空；音标带首尾斜杠。

【可改：背哪套词、放多少个】
默认：大学英语四级高频词，50 个。想背别的就换掉这五个字（六级 / 考研 / 雅思 / 职场商务 / AI 与科技……）。
一次别超过 50，怕你漏词串词；想要 100 就分两批（这一批 50，下一步再补 50）。

【补充：页面一共 6 屏，这一轮只做 2 屏】
首页 / 学习页 / 小测页 / 成绩页 / 完成页 / 错题本。用一个 show(名字) 函数切换，同一时间只显示一屏。这一轮只做前两屏，其余留空壳。

【补充：主按钮的四种状态】
没开始 →「开始今天的学习」；学到一半 →「继续今天的学习（第 N 个）」；今天全部完成 → 置灰不可点，另给一个次级按钮回看。打开时必须是第一种。

【整页不滚动：这一轮就要做成，别等到后面改】
- body 关掉滚动，内容区锁成一屏高（height:100dvh），每一屏自己撑满视口高度
- 只有列表类内容（后面错题本几十条）允许在那张卡片内部滚，页面不动
- 这条优先于「留白大一点」和「标题 30-36px」：留白够看就行，字号用 clamp 自适应（手机标题可压到 22-30px）
- 手机上底部三个入口并排三格，不要把卡片堆得很高

【补充：按钮四条硬规矩】
1. 每个 <button> 写 type="button"
2. 点完立刻取消焦点（否则误按空格/回车会再触发一次，焦点落在返回箭头上就会莫名回首页）
3. 150ms 内的重复点击只算一次（防双击一次跳两个词）
4. 横排的按钮必须显式写宽度，不能继承 width:100%（否则两个 100% 宽按钮把页面撑宽，像捅出卡片）

【风格】（可改）白底蓝色、圆角卡片、留白够看、字看得清。换风格就把下面【视觉细节】的色值整体换掉（比如米色配墨绿）；不管换什么，这三条别动：字看得清、不要花哨动画、不用 emoji。

【视觉细节，照着写，别自己发挥】
配色写成 CSS 变量，全页统一引用：
  --p1:#1E80FF（品牌蓝）--p2:#38BDF8（天蓝）
  --ink:#14161F（正文）--grey:#6B7385（次要文字）--grey2:#9AA3B2（辅助）
  --line:#E6EEF8（描边）--soft:#F3F8FF（浅底）--soft2:#EAF3FF（浅底2）
  --green:#12A672 --amber:#D97706 --danger:#E5484D
  --radius:20px
  --shadow:0 12px 32px rgba(30,96,200,.07), 0 2px 6px rgba(30,96,200,.04)
背景用极浅的蓝白渐变（顶部 #ffffff 到底部 #EAF3FF），不要用纯色。
卡片：白底 + 圆角 20px + 1px 浅描边 + --shadow 阴影。
主按钮：蓝色渐变（90deg，#2B7BF5 → #38BDF8）+ 圆角 + 阴影，白字。
次级按钮：白底 + 1px 描边 + 圆角胶囊，灰字；一组里最多两个是主操作，其余做成文字链接。
标签徽章：圆角小 pill，浅蓝底蓝字。
图标用纯 CSS 或内联 SVG 画（小圆点、勾、环、箭头），不要用 emoji，不要引外部图标库。
字号至少三档：标题 30-36px / 正文 15-17px / 辅助 12-13px。
空状态不能留空：进度为 0 时，环里或旁边要有一句说明（比如「今天还没开始」）。

【电脑和手机两套排法，都要做】
以 900px 为分界（CSS 里用 @media 分开写）。
电脑（窗口 ≥900px）：
- 内容区最宽 960px，水平居中
- 首页主卡片改成左右两栏：左边 2/3 放词库名、「第 N 天」、「今天还有 N 个词没背」和进度条，
  右边 1/3 放圆环进度和「开始今天的学习」按钮，两栏之间留 24px
- 主按钮不要拉满整宽，宽度跟右栏对齐
- 底部的功能入口放进一张卡片里并排，不要做成散落的文字链接
手机（窗口 <900px）：
- 单列纵向堆叠，内容占满宽度，左右各留 16px
- 主按钮可以占满整宽
不要只做手机那一套，然后靠居中把它撑在电脑屏幕上。
底部那张卡片里并排放三个入口：今日词表（今天的几个词）/ 错题本（N 个）/ 浏览全部 N 词。

【发音怎么来】
用浏览器自带的语音合成（speechSynthesis），固定用美式英语 en-US，语速 0.95。
点单词本身和小喇叭按钮都要能读。不要接任何外部接口，不需要 Key。

【做到什么程度算好】
1. 双击打开先看到首页，不是直接进单词卡
2. 首页有「今天还有 7 个词没背」和一个「开始今天的学习」按钮
3. 点按钮进学习页：卡片上有单词、音标、中文释义和一条例句；点小喇叭能听到读音；点「认识」「不认识」换下一个词
4. 从头翻到尾，第 50 个词的音标、释义、例句都正常，没有空字段，没有两个词长得一样
5. 不联网（拔网线或开飞行模式）也能正常用
6. 电脑上不是窄竖条：内容区 ≥900px 居中、首页左右两栏、主按钮没拉满整宽
7. 背景是渐变不是纯色，主按钮有渐变和阴影，页面上没有空着的区域
8. 窗口拉窄到手机宽度：不横向溢出、按钮还点得到、所有按钮都在卡片内部
9. 手机和电脑上都不需要上下滚动，首页和单词卡都一屏看完
10. 页面上没有 emoji，也没有任何外部链接或图标库

【目标】

【内置 6 套，每套 100 个词】
每个词的格式和现有的一致（单词 / 音标 / 词性 / 中文释义 / 英文例句 / 例句中文）。
每套 100 个词——先写 50 个，再用 concat 追加 50 个，不要一次生成 200 个容易乱。

6. AI 与科技：人工智能、大数据相关词汇

【切换入口】
页面里加一个「切换词库」的入口，点开列出所有词库，显示每套的名字、词数和当前进度。选了就切过去，切完给个提示。

【进度怎么存，很关键】
每套词库**单独记**自己的第几天、每个词的状态和历史战绩，互不干扰；但**连续打卡天数是所有词库共用**的。
也就是说：A 词库背到第 20 个，切到 B 再切回来，还是第 20 个。

【词库管理还要有这些操作】
在「管理与备份」里加一块「词库管理」：
- 新建空白词库
- 重命名当前词库
- 删除当前词库（内置的 6 套不能删，只能删自己新建的，删之前二次确认）
- 导入 JSON 词库
- 导出当前词库
- 恢复内置词库
- 一个粘贴框：贴一串英文单词进去（空格、逗号、换行分隔都行），点「解析并补全」，页面里有一份离线词典，命中的自动补上音标、词性、释义和例句，没命中的留空让用户在表格里手填（至少填中文释义）

【显示】
首页底部显示「当前词库：100 词 · 已接触 N · 已掌握 N」。

【验收】
1. 6 套词库都能切换，切过去词数和第几天是对的
2. A 背到第 20 个，切到 B 再切回 A，还是第 20 个
3. 新建一个空白词库，贴 5 个英文单词进去，点解析并补全，能补出音标和释义
4. 想删内置的四级高频，页面提示删不掉

手机适配及添加至桌面
在关卡2 做出来的页面是电脑版，手机上已经能打开、也不会横向溢出。这个选修任务做两件事：一是让它在手机上更好用（按钮够大、字够大、长例句不撑破），二是把链接放到手机桌面，点图标就能背，跟 App 差不多。

步骤 1 ｜ 让它在手机上更好用
把下面这段整段复制，发给 AI。只补三条手感细节，别让它把版式推翻重来。关卡2 做完的页面手机上已经能打开了。觉得手机上已经够用，这一步可以跳过，直接做步骤 2、3。改完在电脑上把浏览器窗口拉窄到 375px，就能看到手机上的样子。
提示词：

提示词 · 点右侧按钮整段复制
复制提示词
先把当前文件复制一份当备份（改坏了能退回来），然后只补手机上的手感细节，版式不要推翻重来。

【前提：手机上已经做好了，这些不要动，也不要重做】
- 窗口变窄（<900px）时变单列、内容占满宽度、左右各留 16px
- 整页不滚动：body 关掉滚动，内容区锁成一屏高（height:100dvh），每一屏自己撑满视口
- 字号用 clamp 自适应，并且按高度分档收紧间距和圆环（≤800 / ≤720 / ≤660 / ≤600 四档）
- 矮手机（<900 宽 且 ≤720 高）首页主卡片已经改成左右两栏
- 窄屏文案会说短话（比如「浏览全部 N 词」→「全部 N 词」），拉宽会自动变回完整写法
- 按钮已经遵守四条硬规矩：type="button"、点完立刻取消焦点、150ms 内重复点击只算一次、
  横排按钮显式写宽度（不能继承 width:100%）

【只补这三处】
1. 主操作的点击区域不小于 44×44：翻词、发音、认识 / 不认识，还有左上角的返回按钮，
   手指点着要够得着。改尺寸时仍然遵守上面那四条硬规矩——尤其是横排按钮，
   要显式写宽度，不能写成 width:100%
2. 单词字号在手机上尽量不小于 32px，要看得清。但「整页不滚动」优先：
   如果 32px 会把一屏撑破，单词最小可以压到 28px，不能再小，并且仍然要一屏看完
3. 例句太长时只显示两行，超出用省略号，不要把卡片撑高、把按钮挤到屏幕外

【补完仍然要一屏看完，这条优先】
补完这三处之后，每一屏在手机上还是要一屏看完，不能出现滚动条。
只有列表类内容（比如错题本几十条）允许在那张卡片内部滚，页面本身不动。

【不要引入这些东西】
不要加 emoji，不要引外部图标库或外部字体，图标一律用纯 CSS 或内联 SVG 画。

【验收】（改窗口尺寸：先打开开发者工具——Windows 按 F12，Mac 按 Command+Option+I；再按 Command+Shift+M / Ctrl+Shift+M 调出手机模拟，就能自己填 390×844）
1. 设成 390×844（手机）看一遍：首页和单词卡都不需要上下滑，也不横向溢出
2. 每个按钮都点得到（不小于 44×44），单词字够大看得清，长例句没有把卡片撑变形
3. 把高度压到 720 和 660 各看一眼：首页和单词卡还是一屏看得完
4. 再设成 1280×800（电脑）看一遍：电脑上没被改坏，还是左右两栏、不用滚动
5. 从头翻 10 个词：连点两次「认识」只前进一个词，随手按空格 / 回车不会回首页、不会跳词
6. 页面上没有 emoji，也没有任何外部链接或图标库
